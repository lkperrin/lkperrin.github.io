# Add a new page to the portfolio

## Steps

1. Ask the user:
   - The name of the new page
   - The content to display
   - Whether to add a button on index.html

2. Read `index.html` and `assets/css/style.css` to understand existing patterns

3. Create the new HTML file following the exact same structure as existing pages (same header, same "← Back" button, same footer)

4. Add the corresponding CSS in `style.css`, respecting the existing palette and typography

5. If needed, add a new button on `index.html`

6. Do NOT commit — let the user validate first
